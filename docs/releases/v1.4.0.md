## Urban Reign PC Port 1.4.0

**English** · [Português abaixo](#português)

The port now runs on Linux too, with the same launcher, mods, controllers and HD textures as on Windows.

### Download and play

**Windows**

1. Download **`UrbanReignPC-1.4.0.zip`** below and extract it anywhere. On Windows this version plays the same as
   1.3.0: coming from 1.3.0 there is no need to update.
2. Open **`Urban Reign.exe`**.
3. In the **Game** tab, pick your own Urban Reign disc image (USA, `SLUS-21209`, `.iso`). The game is **not included**.
4. Press **PLAY**.

**Linux** (pick one)

- **`urban-reign_1.4.0_amd64.deb`** (Debian, Ubuntu, Mint...): `sudo apt install ./urban-reign_1.4.0_amd64.deb` and
  open **Urban Reign** from the applications menu. Settings, saves and your own mods are in
  `~/.local/share/urban-reign` (HD textures go in `~/.local/share/urban-reign/textures/SLUS-21209`).
- **`UrbanReignPC-1.4.0-linux-x86_64.tar.gz`** (any distribution): extract it and run **`urban-reign`**; everything
  stays in that folder, as with the Windows ZIP (`./install-shortcut.sh` adds it to the menu).

Both open the same launcher as on Windows: pick the `.iso` in the **Game** tab and press **PLAY**. The launcher uses
the system's GTK with WebKit; when it is missing it says what to install (`sudo apt install python3-gi
gir1.2-webkit2-4.1`), and `urban-reign --game` starts the game directly.

### What's new

- **Linux version:** a native build of the game. PCSX2's GS renders with Vulkan, and the controllers (SDL3, multitap,
  vibration), the in-game menu (**F2**), save states (**F5** / **F9**), `.pnach` patches, HD textures and the
  CoopTool mod work as on Windows. Measured at 60 frames/s in 4- and 8-fighter fights.
- **Mods on Linux:** DLL mods are `.so` files there (`game/mods/<Name>/<Name>.so`); the mod kit (`modsdk/`) builds
  them with the same API.
- **Building from source on Linux:** `./build.py` with Clang, CMake and Ninja (`tools/linux/install_deps.sh`); the
  Linux guide is [docs/LINUX.md](https://github.com/thiagordsfx/urban-reign-recomp/blob/main/docs/LINUX.md).

### Requirements

- **Windows:** Windows 10 or 11 (64-bit), a DirectX 11 graphics card and the
  [Microsoft Edge WebView2 Runtime](https://go.microsoft.com/fwlink/p/?LinkId=2124703) (already in Windows 11 and in
  an up-to-date Windows 10).
- **Linux:** 64-bit with glibc 2.30 or newer (Ubuntu 20.04+, Debian 11+, Fedora, Arch...) and a Vulkan graphics
  driver; the window is X11 (XWayland on Wayland desktops). Not tested yet on the Steam Deck.
- A processor with SSE4.1.

## Português

O port agora roda também no Linux, com o mesmo launcher, mods, controles e texturas HD do Windows.

### Baixar e jogar

**Windows**

1. Baixe o **`UrbanReignPC-1.4.0.zip`** abaixo e extraia em qualquer pasta. No Windows esta versão joga igual à
   1.3.0: quem já tem a 1.3.0 não precisa atualizar.
2. Abra o **`Urban Reign.exe`**.
3. Na aba **Jogo**, escolha a sua imagem do Urban Reign (EUA, `SLUS-21209`, `.iso`). O jogo **não vem junto**.
4. Aperte **JOGAR**.

**Linux** (escolha um)

- **`urban-reign_1.4.0_amd64.deb`** (Debian, Ubuntu, Mint...): `sudo apt install ./urban-reign_1.4.0_amd64.deb` e
  abra **Urban Reign** no menu de aplicativos. Configurações, saves e os seus mods ficam em
  `~/.local/share/urban-reign` (as texturas HD vão em `~/.local/share/urban-reign/textures/SLUS-21209`).
- **`UrbanReignPC-1.4.0-linux-x86_64.tar.gz`** (qualquer distribuição): extraia e rode o **`urban-reign`**; tudo
  fica nessa pasta, como no ZIP do Windows (o `./install-shortcut.sh` põe no menu).

Os dois abrem o mesmo launcher do Windows: escolha o `.iso` na aba **Jogo** e aperte **JOGAR**. O launcher usa o GTK
com WebKit do sistema; quando falta, ele diz o que instalar (`sudo apt install python3-gi gir1.2-webkit2-4.1`), e o
`urban-reign --game` abre o jogo direto.

### O que há de novo

- **Versão para Linux:** o jogo compilado para Linux. O GS do PCSX2 desenha com Vulkan, e os controles (SDL3,
  multitap, vibração), o menu do jogo (**F2**), os save states (**F5** / **F9**), os patches `.pnach`, as texturas
  HD e o mod CoopTool funcionam como no Windows. Medido a 60 quadros/s em lutas com 4 e 8 lutadores.
- **Mods no Linux:** lá os mods em DLL são arquivos `.so` (`game/mods/<Nome>/<Nome>.so`); o kit de mods (`modsdk/`)
  gera os dois com a mesma API.
- **Compilar no Linux:** `./build.py` com Clang, CMake e Ninja (`tools/linux/install_deps.sh`); o guia do Linux é o
  [docs/LINUX.md](https://github.com/thiagordsfx/urban-reign-recomp/blob/main/docs/LINUX.md).

### Requisitos

- **Windows:** Windows 10 ou 11 (64 bits), placa de vídeo com DirectX 11 e o
  [Microsoft Edge WebView2 Runtime](https://go.microsoft.com/fwlink/p/?LinkId=2124703) (já vem no Windows 11 e no
  Windows 10 atualizado).
- **Linux:** 64 bits com glibc 2.30 ou mais nova (Ubuntu 20.04+, Debian 11+, Fedora, Arch...) e driver de vídeo com
  Vulkan; a janela é X11 (XWayland nos desktops Wayland). Ainda não testado no Steam Deck.
- Processador com SSE4.1.
