## Urban Reign PC Port 1.0.0

**English** · [Português abaixo](#português)

The first release of the Urban Reign PC port: the PS2 game statically recompiled to a native Windows program.

### Download and play

1. Download **`UrbanReignPC-1.0.0.zip`** below and extract it anywhere.
2. Open **`Urban Reign.exe`**.
3. In the **Game** tab, pick your own Urban Reign disc image (USA, `SLUS-21209`, `.iso`). The game is **not included**.
4. Press **PLAY**.

### What's in it

- 60 FPS (progressive scan), including 8-fighter brawls
- 1x to 8x internal resolution, FXAA, texture filtering, sharpening, TV shaders, stretch to the window, fullscreen (F11)
- HD texture packs in PCSX2 format: get the
  [Urban Reign Enhanced HD Textures Pack](https://gbatemp.net/threads/urban-reign-enhanced-hd-textures-pack-updated.665094/)
  and extract it into `game\textures` (it should end up as `game\textures\SLUS-21209\replacements`)
- Xbox, PlayStation and other controllers through SDL3, with vibration; PCSX2-style button mapping; multitap for up
  to 8 players
- PCSX2 `.pnach` mods: put them in `game\mods` and turn them on in the **Mods** tab
- Memory card (PCSX2-compatible) and quick save states (F5 / F9)
- Sofdec videos, music and voices

### Controls (keyboard)

| PS2 | Keyboard |
|---|---|
| ✕ / ○ / □ / △ | ↓ / → / ← / ↑ |
| Left stick | W A S D |
| L1 / R1 / L2 / R2 | Q / E / 1 / 3 |
| L3 / R3 | F / G |
| START / SELECT | Enter / Tab |

### Requirements

Windows 10 or 11 (64-bit), a DirectX 11 graphics card and a CPU with SSE4.1.

### Known issues

- In some runs the opening video's voice plays on the right channel a moment before the left one.
- The "1P VS 1C" selector in the multiplayer menu is missing its colors.

## Português

A primeira versão do port do Urban Reign para PC: o jogo de PS2 recompilado estaticamente para um programa nativo
de Windows.

### Baixar e jogar

1. Baixe o **`UrbanReignPC-1.0.0.zip`** abaixo e extraia em qualquer pasta.
2. Abra o **`Urban Reign.exe`**.
3. Na aba **Jogo**, escolha a sua imagem do Urban Reign (EUA, `SLUS-21209`, `.iso`). O jogo **não vem junto**.
4. Aperte **JOGAR**.

### O que tem

- 60 FPS (progressive scan), inclusive nas lutas de 8
- Resolução interna de 1x a 8x, FXAA, filtros de textura, nitidez, shaders de TV, esticar para a janela, tela cheia
  (F11)
- Pacotes de texturas HD no formato do PCSX2: baixe o
  [Urban Reign Enhanced HD Textures Pack](https://gbatemp.net/threads/urban-reign-enhanced-hd-textures-pack-updated.665094/)
  e extraia em `game\textures` (tem que ficar `game\textures\SLUS-21209\replacements`)
- Controles de Xbox, PlayStation e outros pelo SDL3, com vibração; mapeamento no estilo do PCSX2; multitap para até
  8 jogadores
- Mods `.pnach` do PCSX2: coloque em `game\mods` e ligue na aba **Mods**
- Memory card (compatível com o PCSX2) e save states rápidos (F5 / F9)
- Vídeos Sofdec, música e vozes

### Controles (teclado)

| PS2 | Teclado |
|---|---|
| ✕ / ○ / □ / △ | ↓ / → / ← / ↑ |
| Analógico esquerdo | W A S D |
| L1 / R1 / L2 / R2 | Q / E / 1 / 3 |
| L3 / R3 | F / G |
| START / SELECT | Enter / Tab |

### Requisitos

Windows 10 ou 11 (64 bits), placa de vídeo com DirectX 11 e processador com SSE4.1.

### Problemas conhecidos

- Em parte das vezes, a voz do vídeo de abertura sai no canal direito um instante antes do esquerdo.
- O seletor "1P VS 1C" do menu multiplayer está sem as cores.
